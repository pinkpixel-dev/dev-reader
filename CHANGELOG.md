# Changelog

## 0.1.0 - October 18, 2026

### ✨ Features

- `/dev` opens a pane with the 30 newest DEV posts
- `/dev <tag>` filters posts by tag
- Posts open as rendered markdown with author, date, reading time, reactions, and a link to DEV
- The command runs immediately, even mid-turn
- Keyboard controls: Tab and arrows to move, Enter to open, `b` back, `r` refresh, `q` close

### 🎨 Pane

- Dark charcoal background so the pane stays readable on any terminal theme
- Errors from DEV show inside the pane, not in the transcript
